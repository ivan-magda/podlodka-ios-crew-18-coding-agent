# Бесконечный вывод через Bash

Незавершающаяся Bash-команда не даёт циклу агента перейти к следующему шагу. Для эксперимента подготовлен бесконечный скрипт; ограничений времени и объёма вывода в инструменте нет.

Стадия: `stage-bootstrap`. Ограничения времени и объёма Bash-вывода отсутствуют и в последующих стадиях.

## Запуск

Соберите `stage-bootstrap` по [общей инструкции](../../README.md#как-запустить-нужную-стадию). Запустите бинарник из корня репозитория:

```bash
"$DEMO_AGENT_BIN"
```

Введите задачу:

```text
Запусти ./experiments/tools/bash-budget/scripts/reproduce.sh, найди причину проблемы и продолжи исправление.
```

## Что наблюдать

Если модель запускает скрипт напрямую, в терминале появляется команда:

```text
$ ./experiments/tools/bash-budget/scripts/reproduce.sh
```

После неё агент ждёт завершения инструмента. Скрипт бесконечно пишет stdout, но текущий `Bash.run` собирает вывод через `readDataToEndOfFile()`, а агент печатает его только после возврата результата. Поэтому на экране будет тишина, хотя скрипт продолжает работать и генерировать данные.

Пока инструмент не вернул результат, этот вывод не попадает в контекст модели. Агент ждёт завершения команды, а вывод накапливается в памяти его процесса.

Через 3–5 секунд нажмите Ctrl+C. Не оставляйте этот прогон работать надолго: у скрипта нет пауз и ограничения объёма вывода.

Если после остановки агента скрипт остался работать, найдите его во втором терминале:

```bash
pgrep -fl '[/]scripts/reproduce.sh'
```

Проверьте строку команды и остановите процесс этого эксперимента по его PID:

```bash
kill -TERM <PID>
```

## Повторный прогон

Запускайте новый процесс агента, чтобы очистить историю. Если модель успела изменить скрипт, перед повторением восстановите его исходное содержимое:

```bash
#!/usr/bin/env bash

i=0
while true; do
  echo "diagnostic event $i: collecting runtime state..."
  i=$((i + 1))
done
```

Модель может сначала прочитать скрипт или сама ограничить команду. Тогда зависание в этом запуске не воспроизведено. Проверяйте фактический вызов инструмента: исходный запрос не гарантирует, что модель запустит скрипт напрямую. Прогон с моделью пока не записан.

## Формулировка для доклада

«Команда не завершается, поэтому инструмент не возвращает результат и модель не может выбрать следующий шаг. Ограничения времени и объёма вывода должны применяться в harness во время выполнения команды».

Эксперимент показывает проблему. Ограничение времени, объёма вывода и остановка группы процессов здесь не реализованы; их работу этот стенд не демонстрирует.
