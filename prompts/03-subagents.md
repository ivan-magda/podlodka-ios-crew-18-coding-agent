# M3: Subagents / Context Isolation

Добавь сабагента общего назначения со свежим контекстом. Родительский агент запускает его последовательно через доступный модели инструмент `subagent`.

## SubagentTool

Создай `Subagent.swift` и определи в нём `SubagentTool`.

- `definition` содержит обязательную строку `task`.
- Метод `task(from:)` декодирует аргументы.
- Метод `format(_:)` ограничивает финальный результат 2 000 символами.
- Лимит включает маркер `… subagent result truncated`.

## Запуск

- В `Agent` размести только координацию: параметр `Bool` с именем `allowsSubagents`, список доступных инструментов и метод `executeSubagent`.
- Сначала декодируй `task`.
- Отклони вызов, если текущему агенту запрещены сабагенты.
- Затем напечатай `── subagent ──`.
- Через `defer` напечатай `── main agent ──` перед выходом из обработчика.
- Создай новый экземпляр того же `Agent`.
- Передай тот же клиент, модель и рабочую директорию.
- Новый экземпляр получает свежие `messages` и собственный `Todo`.
- Дочерний агент получает `bash`, файловые инструменты и `todo`.
- Не показывай дочернему агенту инструмент `subagent`.
- Запусти переданную самодостаточную задачу.
- Верни родителю одним результатом инструмента только финальный текст после `SubagentTool.format`.
- Не передавай родителю промежуточную историю дочернего агента.

## Ограничения

- Код будут читать на слайдах. Используй отступ в два пробела и многострочное форматирование.
- Не используй точки с запятой, однострочные блоки, длинные инициализаторы и JSON-схемы в одной строке.
- Сохрани текущие цикл и обработчики прямыми и читаемыми.
- Не добавляй специальные роли, concurrency, scheduler, background jobs, mailbox, persistent child identity, compaction, skills, verification и тесты.
- Не изменяй `README.md` и `prompts/`. Не создавай Git-коммит.
