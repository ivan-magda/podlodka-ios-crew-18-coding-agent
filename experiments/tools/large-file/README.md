# Большой конечный файл

`runtime.log` — готовый файл на 120 000 ASCII-символов, 1 200 строк.

Сравнение: `stage-bootstrap` → `stage-m1-tools`. Соберите выбранную стадию по [общей инструкции](../../README.md#как-запустить-нужную-стадию) и запустите `"$DEMO_AGENT_BIN"` из корня репозитория.

На `stage-bootstrap` попросите агента:

```text
Выполни cat experiments/tools/large-file/runtime.log. Не перепечатывай файл в финальном ответе.
```

Bash вернёт весь файл, включая `END_LARGE_FILE` в конце. Для второго варианта соберите `stage-m1-tools`, запустите новый процесс и попросите:

```text
Прочитай experiments/tools/large-file/runtime.log инструментом read_file. Не переходи к Bash и не перепечатывай файл в финальном ответе.
```

У `read_file` лимит результата — 50 000 символов: ожидаются начало файла и маркер усечения, без `END_LARGE_FILE`. При этом инструмент сначала читает файл целиком: сравнение не показывает ограничение расхода памяти.

В терминале агент печатает только начало результата. Полный размер и маркеры проверяйте в `messages` или журнале вызовов: финальный ответ модели их не подтверждает. Файл синтетический; сохранённого прогона с моделью здесь нет.
