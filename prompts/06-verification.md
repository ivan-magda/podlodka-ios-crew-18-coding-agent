# M6: Verification / Feedback

Добавь обязательную проверку, заданную проектом, перед завершением главного агента.

## Контракт проекта

Создай `.agent/verify.sh`:

```bash
#!/bin/bash
set -e

swift build
git diff --check HEAD
```

- Создай `Sources/AgentCore/Verification.swift`.
- Тип `Verification` хранит путь к скрипту и экземпляр `Bash`.
- Метод `failure() async throws -> String?` возвращает `nil`, если скрипт отсутствует.
- Этот метод также возвращает `nil`, если скрипт завершился с exit code `0`.
- При другом exit code метод возвращает вывод команды.
- Измени `Bash.run`, чтобы он возвращал `(output: String, exitCode: Int32)`.
- Сохрани в `output` прежний полный текст Bash, включая строку `Exit code: <status>`.
- Перенеси печать `$ <command>` в `Bash.run`, чтобы любая команда печаталась ровно один раз.
- Метод `Bash.execute` возвращает модели только значение `output`.

## Завершение задачи

Для каждого ответа `.assistant` сохрани текущий порядок:

1. Добавь ответ в `messages`.
2. Запусти существующий micro-compact.
3. Если ответ содержит вызовы инструментов, напечатай его непустой текст.
4. Обработай каждый вызов через существующий `executeTool`.

Ответ без вызовов инструментов считается попыткой завершения. До печати финального текста вызови проверку проекта.

- Оставь отдельную печать текста для ответа с вызовами инструментов.
- Обработай попытку завершения в одной ветке и вызови `failure()` ровно один раз.
- Не запускай verification в других местах цикла.
- Если `failure()` вернул `nil`, напечатай непустой финальный текст и верни его.
- При ошибке напечатай `Verification failed` и первые 200 символов вывода с отметкой об обрезке.
- Не печатай отклонённый финальный текст.
- Добавь полный вывод, включая exit code, в `messages` как сообщение `.user` с просьбой исправить проблему.
- Продолжи тот же цикл агента.

- Главный `Agent` хранит optional `Verification`.
- Добавь в initializer параметр `Bool` с именем `verifiesCompletion` и значением по умолчанию `true`.
- При создании subagent передай `verifiesCompletion: false`.
- Ответ subagent не завершает задачу родительского агента.

## Ограничения

- Код будут читать на слайдах. Используй отступ в два пробела и многострочное форматирование.
- Не используй точки с запятой, однострочные блоки и длинные инициализаторы в одной строке.
- Не добавляй hooks framework, конфиг нескольких команд, инструмент `finish`, retry limit, CI, verifier-agent и тесты.
- Не изменяй `README.md` и `prompts/`. Не создавай Git-коммит.

## Проверка

Выполни `/bin/bash .agent/verify.sh` и `git diff --check`.
