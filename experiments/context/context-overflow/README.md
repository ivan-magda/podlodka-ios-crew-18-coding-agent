# Переполнение контекста после большого Bash-вывода

Агент получает большой результат Bash и отправляет его в следующем запросе к модели. Если история превышает лимит контекста, API отклоняет запрос.

`scripts/flood.sh` печатает конечный поток синтетических шестнадцатеричных строк и завершается. По умолчанию — 1 000 000 ASCII-байтов; размер задаётся первым аргументом. Нужен Python 3. Строки различаются, чтобы не сводить нагрузку к повторению одного символа. Реальных ключей и пользовательских данных в них нет.

## Запрос агенту

Используйте `stage-m4a-micro-compact` — стадию **до auto-compact**. Соберите её по [общей инструкции](../../README.md#как-запустить-нужную-стадию), запустите `"$DEMO_AGENT_BIN"` из корня репозитория и вставьте одну строку:

```text
Прочитай experiments/context/context-overflow/prompt.md и выполни описанное в нём задание.
```

Можно сразу передать команду, меняя размер при необходимости:

```text
Выполни bash experiments/context/context-overflow/scripts/flood.sh 1000000 без перенаправления и усечения вывода. После завершения кратко подтверди результат.
```

## Что должно произойти

1. Скрипт завершается; Bash возвращает большой результат в `messages`.
2. Следующий запрос передаёт эту историю API.
3. Если запрос превышает лимит контекста выбранной модели, API отклоняет его.
4. CLI перехватывает ошибку из `agent.run` и печатает `Error: …`. Выполнение задачи прерывается, но REPL продолжает принимать ввод.

Micro-compact не уберёт этот результат перед запросом: он сохраняет последние пять результатов и выполняется только после успешного ответа модели. Одного большого свежего результата может быть достаточно, чтобы превысить лимит.

Размер в байтах не равен числу токенов. Лимит зависит от выбранной модели и настроек API. Начните с 1 MB; этого может не хватить для переполнения. Если запрос принят, в новой сессии увеличьте аргумент, например до `2000000`. Сервер может раньше отклонить запрос по размеру HTTP-body. Тогда для проверки именно лимита контекста потребуется другой объём вывода или другая конфигурация модели.

Сохраняйте фактическую ошибку. Превышение размера HTTP-запроса, rate limit, таймаут или нехватка памяти не подтверждают переполнение контекста. SDK может обернуть ошибку API своей ошибкой: сохраняйте доступную диагностику без ключей и заголовков авторизации. Для повторения выйдите через `exit` и запустите новый процесс: большой результат остаётся в истории неудачной сессии.

## Граница сравнения с auto-compact

M4b тоже может не справиться с таким объёмом: запрос на краткий пересказ получает всю сериализованную историю и сам может превысить лимит контекста. Если этот запрос завершится ошибкой, история сохранится и агент отправит обычный запрос, который тоже может быть отклонён.

Для показа сжатия используйте соседний эксперимент [auto-compact](../auto-compact/README.md) с меньшим логом. Условие его запуска: история пересекает локальный порог сжатия, но ещё помещается во вход модели. Для auto-compact нужен запас до жёсткого лимита; слишком большой результат инструмента приходится ограничивать отдельно.

Генератор проверен локально. Записи запуска с моделью и ошибки переполнения контекста здесь пока нет.
