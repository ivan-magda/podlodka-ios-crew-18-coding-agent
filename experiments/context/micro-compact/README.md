# Micro-compact: восемь больших результатов

В `files/` лежат восемь синтетических логов: первые семь по 6 000 ASCII-символов, восьмой — 6 106. Генерировать или копировать их не нужно.

Сравнение: `stage-m3-subagents` → `stage-m4a-micro-compact`. Соберите M4a по [общей инструкции](../../README.md#как-запустить-нужную-стадию), запустите `"$DEMO_AGENT_BIN"` из корня репозитория и вставьте одну строку:

```text
Прочитай experiments/context/micro-compact/prompt.md и выполни описанное в нём задание.
```

При восьми последовательных вызовах `read_file` без других инструментов ожидается:

```text
до:     [file1][file2][file3][file4][file5][file6][file7][file8]
после:  [маркер][маркер][маркер][file4][file5][file6][file7][file8]
```

На M4a последние пять результатов инструментов сохраняются. Более старые результаты длиннее 2 000 символов заменяются маркерами; идентификаторы вызовов сохраняются. Чтение самого `prompt.md` даёт короткий результат, который не подлежит замене.

Следите за сообщениями micro-compact: суммарно должны замениться три результата чтения, возможно по одному в разных итерациях. Очистка выполняется после ответа модели и до добавления новых результатов инструментов. Поэтому после восьмого чтения дождитесь следующего ответа модели: после него пройдёт очистка, даже если ответ уже финальный.

Дополнительные вызовы инструментов меняют состав последних пяти результатов. Если они появились или модель прочитала всё одним Bash-вызовом, схема выше уже не описывает этот запуск — проверяйте фактическую последовательность.

В терминале видно только превью из 200 символов. Чтобы увидеть конкретные замены, проверьте `messages` в отладчике или сохранённой записи запуска; счётчик показывает только количество замен. Следующий запрос в той же сессии будет использовать уже сокращённую историю.

Для сравнения повторите тот же запрос на `stage-m3-subagents`: результаты останутся полными. Каждый вариант запускайте в новом процессе агента.

Эксперимент проверяет сокращение объёма истории. Он не измеряет качество ответа. Файлы проверены; записи запуска с моделью и сжатия этих результатов пока нет.

## Вариант с семью файлами для короткого показа

```text
Прочитай experiments/context/micro-compact/prompt.md и выполни задание только для первых семи файлов; восьмой не читай.
```

В этом варианте после следующего ответа модели ожидаются два маркера и пять полных результатов. Так устроена выбранная сцена доклада.
