# M2: Planning / State

Добавь `Todo.swift`. Он хранит состояние многошаговой задачи отдельно от `messages`. Добавь доступный модели инструмент `todo`.

## Todo

- Создай `Todo` как `final class`.
- Каждый `Agent` хранит `private let todo = Todo()`.
- `Todo` сохраняется между вызовами `run` этого агента.
- Метод `execute(_ arguments: String) throws -> String` принимает полный снимок списка.
- Аргументы содержат обязательный массив `items`.
- Каждый элемент содержит обязательные поля `id`, `text` и `status`.
- Поле `status` принимает `pending`, `in_progress` или `completed`.
- Отрази все поля, enum-значения и `additionalProperties: false` в JSON Schema.
- Используй закрытые типы `Decodable`.

- Сначала декодируй и проверь новый снимок.
- Разрешай не более одного элемента `in_progress`.
- После успешной проверки атомарно замени текущее состояние.
- При ошибке сохрани предыдущее состояние.
- Успешный вызов возвращает строки `[ ] id: text`, `[>] id: text` и `[x] id: text`.
- Свойство `hasOpenItems` проверяет статусы элементов, а не только наличие элементов.
- Подключи `todo.execute` напрямую к существующему локальному словарю обработчиков.
- Не добавляй closure и `weak self`.
- Не меняй тип результата `executeTool`.
- Печатай результат `todo` в консоли без обрезки.
- Добавь в системный промпт короткую инструкцию использовать `todo` для многошаговых задач.

## Напоминание

В начале каждого `run` установи счётчик итераций без `todo` в `0`. После каждого ответа с вызовами инструментов определи, был ли среди них `todo`.

- Если ответ содержит `todo`, сбрось счётчик в `0`.
- Если ответ не содержит `todo`, увеличь счётчик на `1`.
- Начиная со значения `3`, при открытых пунктах создай напоминание с текущим снимком и вызови `print(reminder)`.
- Добавляй напоминание как сообщение `.user` после всех результатов инструментов текущей итерации.
- Не сбрасывай счётчик после напоминания. Его сбрасывает только вызов `todo`.

## Ограничения

- Код будут читать на слайдах. Используй отступ в два пробела и многострочное форматирование.
- Не используй точки с запятой, однострочные блоки, длинные инициализаторы и JSON-схемы в одной строке.
- Не добавляй persistence, DAG, subagents, compaction, skills, verification, общие manager abstractions и тесты.
