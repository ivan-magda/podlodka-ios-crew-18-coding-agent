# M5: Skills / Progressive Disclosure

Добавь локальные для проекта skills из файлов `skills/<directory>/SKILL.md`. Создай `Sources/AgentCore/Skills.swift`.

## Загрузка

- При создании каждого `Agent` один раз просканируй непосредственные подкаталоги `skills`.
- Не сканируй каталог повторно для этого экземпляра.
- Frontmatter начинается первой строкой `---` и заканчивается следующей строкой, равной `---`.
- Прочитай из него однострочные непустые `name` и `description`.
- Считай весь текст после frontmatter полем `body`.
- Пропускай файл без двух границ, `name` или `description`.
- Сортируй skills по `name`.

- `Skills` предоставляет текст для системного промпта, definitions инструментов и метод `load(_ arguments: String)`.
- Создай экземпляр `Skills` при создании `Agent`.
- Добавь его текст в системный промпт.
- Через Swift-интерполяцию добавь в этот текст фактические строки каталога, а не имя переменной `catalog`.
- Добавь его definitions в список инструментов.
- Подключи `skills.load` в существующем словаре обработчиков.
- Не добавляй отдельную ветку `load_skill` в `Agent.executeTool`.

## Progressive disclosure

В системный промпт добавляй только каталог `name: description` и короткую инструкцию использовать `load_skill`. Не добавляй body skills в системный промпт.

Если каталог непуст, добавь инструмент `load_skill(name)`. Если каталог пуст, не добавляй ни каталог, ни инструмент.

- `load_skill` возвращает body выбранного skill внутри явного `<skill>` marker.
- При неизвестном имени выброси обычную ошибку обработчика инструмента.
- Добавляй результат `load_skill` только в контекст агента, который вызвал инструмент.
- При создании subagent повторно просканируй тот же каталог.
- Не передавай subagent body, который загрузил родительский агент.

Добавь короткий пример на русском языке в `skills/example/SKILL.md`.

## Ограничения

- Код будут читать на слайдах. Используй отступ в два пробела и многострочное форматирование.
- Не используй точки с запятой, однострочные блоки, длинные инициализаторы и JSON-схемы в одной строке.
- Не подключай YAML-библиотеку.
- Не добавляй global scopes, precedence, hot reload, resolver, специальную поддержку references/assets/scripts, новый manager и тесты.
- Не изменяй `README.md` и `prompts/`. Не создавай Git-коммит.
