# Большой результат Bash

Выполни в основном агенте одну Bash-команду:

```bash
bash experiments/context/context-overflow/scripts/flood.sh
```

Дождись завершения команды. Не перенаправляй вывод в файл, не сокращай его через `head`, `tail` или другие фильтры и не передавай задачу субагенту. После получения результата кратко подтверди завершение; сам вывод не перепечатывай в финальном ответе.
