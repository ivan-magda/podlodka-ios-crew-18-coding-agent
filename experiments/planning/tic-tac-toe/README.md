# Крестики-нолики: многошаговая задача для M2

Агент создаёт консольную игру по заданию из `prompt.md`. Один и тот же запрос позволяет сравнить работу со списком Todo и без него.

Сравнение: `stage-m1-tools` → `stage-m2-planning`. Соберите выбранную стадию по [общей инструкции](../../README.md#как-запустить-нужную-стадию) и запустите агент из корня репозитория:

```bash
"$DEMO_AGENT_BIN"
```

Вставьте в REPL одну строку:

```text
Прочитай experiments/planning/tic-tac-toe/prompt.md и выполни описанное в нём задание.
```

REPL принимает одну строку. Полное задание агент читает из файла через `read_file` или Bash.

Приложение должно появиться в `experiments/planning/tic-tac-toe/app/`. Команду запуска готовой игры даст агент.

## Что наблюдать

Дайте тот же запрос агенту до и после добавления `todo`. На M2 наблюдайте создание списка и обновление статусов по ходу работы. Использовать Todo для многошаговых задач предлагает системный промпт M2; само задание игры остаётся одинаковым.

Наличие Todo не доказывает, что игра работает. Сборку, тесты и ручную партию проверяйте отдельно. Если модель не использовала `todo`, зафиксируйте это как результат запуска.

Для повторения с нуля завершите агент через `exit`, уберите или переименуйте только созданный каталог `app/` и запустите новый процесс. `prompt.md` и этот README сохраните. Записей запусков с моделью здесь пока нет.
