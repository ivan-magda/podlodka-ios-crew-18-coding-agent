# M4a: Micro-compact

Добавь детерминированный micro-compact старых результатов инструментов в каждый `Agent`.

После успешного ответа модели добавь сообщение `.assistant` в `messages`. Затем запусти compaction до добавления новых результатов инструментов.

- Найди все сообщения `.tool`.
- Оставь последние пять сообщений `.tool` без изменений.
- В каждом более старом сообщении `.tool` проверь длину `content`.
- Если `content` длиннее 2 000 символов, замени его коротким маркером с предложением перечитать источник.
- Сохрани исходный `tool_call_id`.
- Сохрани вызовы инструментов из сообщений `.assistant`, короткие результаты и все остальные сообщения.
- Напечатай количество заменённых результатов.

Не изменяй результаты инструментов, добавленные после micro-compact текущей итерации, до следующего запроса модели. Родительский и дочерний агенты обрабатывают только собственные массивы `messages`.

## Ограничения

- Код будут читать на слайдах. Используй отступ в два пробела и многострочное форматирование.
- Не используй точки с запятой и однострочные блоки.
- Не добавляй summary-вызов модели, token estimator, transcript storage, manual compact tool, новый manager и тесты.
- Не изменяй `README.md` и `prompts/`. Не создавай Git-коммит.

## Проверка

Выполни `swift build` и `git diff --check`.
