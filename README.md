# Кодинг-агент для Podlodka iOS Crew 18

Кодинг-агент на Swift для доклада «Простой цикл, сложный агент: как устроен кодинг-агент».

## Bootstrap

На первом этапе агент состоит из одного цикла и одного инструмента:

```text
пользователь → модель → Bash → результат инструмента → модель
```

Агент хранит историю диалога в памяти и передаёт модели описание Bash-инструмента. Если модель запрашивает инструмент, агент выполняет команду, добавляет результат к истории и снова вызывает модель. Ответ без вызова инструмента завершает цикл.

## Требования

- macOS 13 или новее
- Swift 6.2 или новее
- модель с поддержкой вызова инструментов (tool calling)

## Настройка

Возьмите список переменных из `.env.example`. Задайте их в shell или подключите файл с переменными, который лежит за пределами рабочей директории агента:

```bash
export PODLODKA_OPENAI_API_KEY=your-api-key
export PODLODKA_OPENAI_BASE_URL=https://api.openai.com/v1
export PODLODKA_OPENAI_MODEL=your-tool-capable-model
```

## Сборка и запуск

```bash
swift build
swift run agent
```

Агент использует каталог, из которого вы его запускаете. Введите `exit`, чтобы завершить REPL.
