# Кодинг-агент для Podlodka iOS Crew 18

Учебный кодинг-агент на Swift к докладу «Простой цикл, сложный агент: как устроен кодинг-агент». Репозиторий показывает, как вокруг простого цикла работы с моделью появляются инструменты, план, субагенты, управление контекстом, skills и проверка результата.

Код намеренно упрощён, чтобы каждый механизм можно было разобрать отдельно и проследить изменения от этапа к этапу.

## Как устроен агент

В основе агента — цикл:

```text
пользователь → модель → вызов инструмента → результат → модель → …
```

Агент хранит историю диалога в памяти и передаёт модели описания доступных инструментов. По запросу модели агент вызывает инструмент, добавляет результат в историю и снова обращается к модели.

Ответ без вызова инструмента означает попытку завершить задачу. Если в проекте настроена проверка результата и она не прошла, агент продолжает работу.

Основной цикл находится в [Agent.swift](Sources/AgentCore/Agent.swift), а чтение пользовательского ввода и настройка API — в [main.swift](Sources/AgentCLI/main.swift).

## Этапы

В `main` собраны все этапы. Каждый из них отмечен Git-тегом:

| Тег                       | Что добавляется                                                            |
| ------------------------- | -------------------------------------------------------------------------- |
| `stage-bootstrap`         | Минимальный цикл с одним инструментом — Bash                               |
| `stage-m1-tools`          | Чтение, запись и редактирование файлов с проверкой путей                   |
| `stage-m2-planning`       | Список задач со статусами и напоминание обновлять его                      |
| `stage-m3-subagents`      | Передача подзадачи агенту с отдельной историей диалога                     |
| `stage-m4a-micro-compact` | Удаление содержимого старых объёмных результатов инструментов из контекста |
| `stage-m4b-auto-compact`  | Замена длинной истории кратким пересказом, который составляет модель       |
| `stage-m5-skills`         | Каталог skills и загрузка инструкций по запросу модели                     |
| `stage-m6-verification`   | Проверка результата перед завершением задачи                               |

Для последовательного знакомства с кодом начните с `stage-bootstrap` и сравнивайте соседние этапы:

```bash
git diff stage-bootstrap stage-m1-tools -- Sources
```

В [prompts/](prompts/README.md) лежат промпты для самостоятельного воспроизведения каждого этапа с помощью кодинг-агента. Тег `stage-start` содержит промпты без реализации агента.

## Требования

- macOS 13 или новее
- Swift 6.2 или новее
- доступ к OpenAI-совместимому Chat Completions API и модель с поддержкой вызова инструментов (tool calling)

## Настройка

Задайте переменные окружения по образцу [.env.example](.env.example), подставив свой API-ключ и идентификатор модели:

```bash
export PODLODKA_OPENAI_API_KEY=your-api-key
export PODLODKA_OPENAI_BASE_URL=https://api.openai.com/v1
export PODLODKA_OPENAI_MODEL=your-tool-capable-model
```

Ключ и модель обязательны. `PODLODKA_OPENAI_BASE_URL` можно не задавать: по умолчанию используется `https://api.openai.com/v1`. Если храните переменные в файле, разместите его за пределами рабочей директории агента и подключите через `source`. Агент не загружает `.env` автоматически.

## Сборка и запуск

В каталоге репозитория выполните:

```bash
swift build
swift run agent
```

После запуска напишите агенту, что нужно сделать. Агент работает в каталоге, из которого его запустили. Чтобы работать с другим проектом, после сборки перейдите в его каталог и запустите бинарный файл агента по абсолютному пути:

```bash
cd /path/to/test-project
/path/to/podlodka-ios-crew-18-coding-agent/.build/debug/agent
```

Пути в примере нужно заменить своими. Введите `exit`, чтобы завершить работу.
